# Euclid's Elements in the real plane

This work adapts Books I–VI of Euclid's *Elements*, using Richard Fitzpatrick's revised 2008 translation, to current Litex. Points are real coordinate pairs. The mathematical foundation is Litex's real-number model and the existing analytic geometry library. Differences from Euclid's synthetic constructions are recorded alongside each source item.

The scope is 173 numbered propositions, 74 foundation items (64 definitions, five postulates and five common notions), and all source corollaries. No whole book is complete.
