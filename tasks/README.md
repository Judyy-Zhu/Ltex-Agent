# 《几何原本》13 卷任务清单

本清单将新的 Lean / Litex 对比实验范围扩展到《几何原本》I–XIII 卷。按 Richard Fitzpatrick 修订于 2008 年的同一原文版本，包含 **465 个编号命题**，以及 **130 个定义、5 个公设、5 个公理、24 个显式推论和 15 个显式引理**，合计 **644 个可定位的源文任务**。与此前 I–IV、VI 卷的 148 个编号命题相比，增加 317 个编号命题。

原文：[Euclid’s Elements of Geometry, revised 2008](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf)。卷号、编号和 PDF 坐标均从该文件提取并检查连续性；不混用其他版本的增补命题。目录中的 PDF 页码从 1 开始，坐标单位是从页面顶部计量的 PDF 点。

这里完成的是任务目录和原文定位。两种语言的新实验状态均为 `not_started`，没有据此增加已证明数量。逐项正式目标、跨语言语义等价性及逻辑依赖还需要审核。旧证明、历史检查点和原有 148 项范围记录保留原样；新实验以本清单为准。

## 各卷范围

- I：48 个命题，平面几何基础。
- II：14 个命题，几何代数。
- III：37 个命题，圆与切线。
- IV：16 个命题，内接与外切构造。
- V：25 个命题，量与比例；恢复为完整一卷的任务。
- VI：33 个命题，比例与相似。
- VII：39 个命题，整数、整除、最大公约数。
- VIII：27 个命题，连比例整数。
- IX：36 个命题，数论与数列。
- X：115 个命题，可通约量与无理量分类。
- XI：39 个命题，立体几何基础。
- XII：18 个命题，面积、体积与穷竭法。
- XIII：18 个命题，正多面体。

所有卷合计 465 个编号命题。主准确率分母固定为 465；定义、源公设、公理、推论、引理分别统计，不混入这个分母。

## 文件与任务标识

- `catalog.json`：范围、源文件 SHA-256、分卷计数、实验边界和准备状态。
- `tasks.jsonl`：全部 644 项，按源文顺序排列，每行一个任务。
- `propositions.jsonl`：465 个编号命题。
- `foundations.jsonl`：140 个基础条目，包括定义、公设与公理。
- `supplements.jsonl`：39 个显式推论与引理。
- `build_catalog.py`：从同一 PDF 重建目录。
- `validate_catalog.py`：检查编号连续性、唯一 ID、分类分区、坐标区间和源文件哈希。
- `task_cli.py`：筛选、查看、生成 agent 提示词以及渲染任务原文页面。
- `sources/elements-2008.pdf`：本地原文缓存，已加入忽略规则；JSONL 不复制现代译文。

编号命题 ID 如 `EUCLID.I.P001`、`EUCLID.X.P115`、`EUCLID.XIII.P018`。定义 ID 如 `EUCLID.V.D005`。推论和引理使用各卷内的独立序号，如 `EUCLID.X.LEM001`；`preceding_proposition` 只表示它在原文中的相邻位置，不表示它属于该命题或构成已审核依赖。

每项包含共同的 Lean / Litex 任务指令、原文起止页和纵坐标、验收要求、待审核的依赖状态以及两种语言各自的新运行状态。任务的数学规格来自精确定位的原文，而不是重复的通用指令或名称；运行时必须把原文页面提供给 agent。

## 使用

从本项目目录执行以下命令，不调用模型 API，也不运行数学证明实验：

```bash
# 查看第十三卷全部编号命题。
python3 tasks/task_cli.py list --book 13 --kind proposition

# 查看某项的结构化规格及原文位置。
python3 tasks/task_cli.py show EUCLID.XIII.P018

# 为两种语言准备相同源文范围的任务提示词。
python3 tasks/task_cli.py prompt EUCLID.I.P001 --language litex
python3 tasks/task_cli.py prompt EUCLID.I.P001 --language lean

# 按需渲染页面，包括原文图形；每次使用新的输出目录。
python3 tasks/task_cli.py prompt EUCLID.I.P001 --language litex \
  --render-dir /tmp/euclid-I1-source

# 检查目录和原文缓存。
python3 tasks/task_cli.py validate

# 用冻结原文重建同一目录。
python3 tasks/build_catalog.py tasks/sources/elements-2008.pdf
```

查看和筛选只需要 Python 标准库。重建目录需要 `pdftotext`，渲染需要 `pdftoppm`。本机已提供 Poppler。复制项目到另一台机器后，从 `catalog.json` 的原文 URL 恢复 PDF 缓存，并核对其中 SHA-256；不要用其他版本静默替换。提示词生成和验证命令遇到源文件不匹配会拒绝继续。

## 原文覆盖与验收

465 个编号命题已经逐卷检查为完整连续编号，130 个定义单独定位，包括第 X 卷中途出现的第二组、第三组定义。推论和引理目录覆盖明确标题；未单列标题的附加结论留在其所属任务的原文区间，必须在语义审核时列出并完成，不能因为没有标题而忽略。

显式标题目录不能替代逐条结论审核。主建库实验前，每个选定源文任务需冻结语言无关的完整数学验收规格；正式目标由 agent 自行形式化，之后核对原文语义。只有辅助的“固定目标证明”实验预先提供一对数学等价的正式目标，避免把两种实验混淆。第 III 卷命题 16 等包含多种结论的条目不能只完成容易的部分就算成功；第 XIII 卷最后命题后的分类讨论也不能漏掉。第 XIII 卷卷末的独立引理已单列任务。

主建库实验向双方提供原文命题、原文证明和图形；这是“根据原典进行形式化建库”的实验。它与不给原文证明的独立证明发现实验不同，不应混合报告。历史 `.lit` 证明、checkpoint、带答案的经验文件和另一语言的输出不进入 agent 工作区。Pi 工具的读取范围需要实际限制，设置 `cwd` 本身不足以隔离文件。

验收同时要求完整源文语义、固定版本下新进程验证通过、没有超出统一批准基础的未证明依赖。证明失败不转为公理。原典公设和公理采用何种模型解释、哪些作为批准基础，须事先统一；不能把所有新基础条目自动当作允许假设，也不能要求用同一错误标准把所有原典公设判为证明失败。

## 全书所需模型

原有二维几何库只覆盖部分基础，扩展到 13 卷需要新增模型接口：

- I–VI：平面几何、角度、构造、面积，以及保留同类量区别的比例体系。
- VII–IX：数、单位、整除和整数比例。原文中的单位与“数”有区别，不能直接不加说明地改成包含 0、1 的统一自然数域。
- X：相对于给定参考量的可通约性、可通约于平方、比例及无理量类别。不能只用“不是有理数”的一个谓词替代整卷分类。
- XI–XIII：三维点线面、实体、相似、角、面积、体积、穷竭论证和正多面体构造。二维 `cart(R,R)` 不足以表达这些任务。

主实验采用现代解析模型时，要明确报告它证明的是该模型中的原典数学内容，不宣称仅由欧几里得五公设导出所有结果。两种语言采用数学等价的批准基础，禁止直接导入待测目标及其等价结论。定义建模、共享引理和最终集成的时间均保留在完整建库成本中。
